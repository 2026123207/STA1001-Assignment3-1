## 과제 내용

음료의 공칭 평균 용량은 500mL. 36개 표본의 평균은 496mL이고 모표준편차는 12mL로 알려져 있을 때, 실제 평균이 500mL보다 작은지 유의수준 5%에서 단일표본 Z-검정으로 확인합니다.

1. 가설 설정 (H₀: μ = 500, H₁: μ < 500)
2. 표준오차 σ/√n
3. Z-검정통계량
4. 임계값
5. p-value
6. if/else로 귀무가설 기각 여부 판정
7. 기각역을 표시한 그래프
